\section*{Nội dung Prompt Tối Ưu}
Dưới đây là prompt đã được tối ưu hóa, chi tiết và rõ ràng hơn để bạn có thể sử dụng yêu cầu các mô hình AI hỗ trợ lập trình:

\begin{quote}
\textbf{Vai trò:} Kỹ sư phần mềm Full-stack \& Chuyên gia AI.

\textbf{Nhiệm vụ:} Hướng dẫn thiết kế và xây dựng một website Hệ thống Quản lý Kho hàng (Warehouse Management System - WMS) có tích hợp AI, sử dụng Python làm nền tảng chủ đạo (Backend và mô hình AI).

\textbf{Yêu cầu chi tiết:}
\begin{itemize}
    \item \textbf{Tính năng cốt lõi (Core WMS):} Quản lý xuất/nhập/tồn kho, quản lý danh mục sản phẩm, theo dõi vị trí lô hàng, báo cáo thống kê theo thời gian thực, quản lý đối tác và phân quyền người dùng.
    \item \textbf{Tính năng AI tích hợp:} 
    \begin{itemize}
        \item Dự báo nhu cầu nhập hàng (Demand Forecasting).
        \item Nhận diện/Phân loại hoặc trích xuất thông tin hàng hóa từ hình ảnh camera (Computer Vision).
        \item Tối ưu hóa vị trí sắp xếp trong kho hoặc lộ trình lấy hàng bằng thuật toán tìm đường.
    \end{itemize}
    \item \textbf{Kiến trúc \& Công nghệ:} Cần đề xuất kiến trúc cụ thể. Ưu tiên sử dụng Web Framework Python (ví dụ: Django hoặc FastAPI), Cơ sở dữ liệu (PostgreSQL kết hợp Redis), và các thư viện AI phù hợp (Scikit-learn, TensorFlow, OpenCV).
    \item \textbf{Lộ trình triển khai (Step-by-step):} Cung cấp các bước thực hiện cụ thể:
    \begin{enumerate}
        \item Thiết kế kiến trúc và mô hình Cơ sở dữ liệu (Database Schema).
        \item Xây dựng API Backend với Python.
        \item Huấn luyện và đóng gói (Deploy) mô hình AI thành API riêng.
        \item Đề xuất công nghệ Frontend phù hợp để kết nối hệ thống.
    \end{enumerate}
\end{itemize}
\end{quote}
